# Fuentes

Los cuatro ficheros `.woff2` de esta carpeta son las versiones variables, subset `latin`,
que sirve Google Fonts. Se guardan en el repo para que el build no dependa de la red
(ver `src/app/fonts.ts`).

| Fichero | Familia | Licencia |
|---|---|---|
| `Manrope-latin-var.woff2` | Manrope | SIL Open Font License 1.1 |
| `SpaceGrotesk-latin-var.woff2` | Space Grotesk | SIL Open Font License 1.1 |
| `Montserrat-latin-var.woff2` | Montserrat | SIL Open Font License 1.1 |
| `Inter-latin-var.woff2` | Inter | SIL Open Font License 1.1 |

Origen: https://fonts.google.com — OFL 1.1 permite usar, copiar y redistribuir la fuente,
también dentro de un producto, siempre que no se venda por separado ni se use su nombre
para una fuente derivada.

Descargadas el 23 nov 2026 con el mismo user-agent que usa `next/font`
(Chrome 104, que fuerza el formato `woff2`).
